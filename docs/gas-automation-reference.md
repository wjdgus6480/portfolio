# GAS 자동화 프로젝트 참고 자료

포트폴리오 `GAS Automation System` 작성용 근거 정리 · 2026-11-23 확인

**확인한 자료**
- 스프레드시트 3개 (셀 값 읽기만, 실행 버튼 · 메뉴는 누르지 않음)
- 각 시트에 연결된 Apps Script 편집기의 실제 코드, 트리거 목록, 실행 기록(최근 7일)과 오류 로그
- PC의 코드 파일 · 결과물 PDF/PPTX, 사용자가 보내준 메일 수신 캡처

여기 적힌 것만 포트폴리오에 쓴다. "미확인"은 증거가 생기기 전까지 완료된 기능으로 쓰지 않는다.

## A. 유튜브 트렌드 리포트 (핵심 사례)

### 흐름
YouTube API로 영상 100개 수집 → 시트에 저장 → NVIDIA AI가 트렌드 분석(JSON) → Slides 템플릿에 채우기 → PDF · PPTX로 변환해 Drive에 저장 → 두 파일을 첨부해 메일 발송

| 11-22 15:32~16:22 | 웹 앱 열기(2번째 배포) | **10번 실패** (아래 실패 ②) |

- 결과물 파일: `유튜브 트렌드 리포트_2026-11-20.pdf`(7장) · `.pptx`
- 한 번 실행에 약 2~3분

### 실제 코드(편집기)의 구성
- `Code.gs` — 수집 · AI 분석 · 슬라이드 · PDF/PPTX · 메일 · 웹 앱 (PC의 코드 파일과 같은 내용)
- 대시보드 파일 — 시트에 실행 체크박스 · 실행 상태 · 최근 결과 · 생성 파일 링크를 만들고, 체크하면 실행되는 **수정 시 트리거**를 설치
- `CollectionDataDesign.gs` — 수집데이터 시트 서식 정리(데이터 · 열 순서는 그대로)

### 구현 포인트
| 단계 | 어떻게 |
|---|---|
| 수집 | 인기 급상승 목록을 50개씩 두 번 받아 100개. 카테고리 이름 변환, 영상 길이로 쇼츠 판별, 시간당 조회수 계산, 전날 목록과 비교해 신규 진입 표시 |
| AI 분석 | 정해진 JSON 형식으로만 답하게 하고, 슬라이드 칸에 맞게 항목별 글자 수 제한 |
| AI 답 검사 | JSON만 잘라 읽기 → 필수 항목 7개 · 항목별 개수 · 답이 잘렸는지 확인, 하나라도 틀리면 슬라이드를 만들지 않고 멈춤 |
| 슬라이드 | 템플릿을 복사해 `{{항목}}` 50여 곳을 채움 |
| PDF · PPTX | PDF는 Drive 변환, PPTX는 Slides 내보내기 주소를 로그인 토큰으로 호출 |
| 메일 | 핵심 트렌드 · 추천 콘텐츠 · 시간당 조회수 TOP 10 본문 + PDF · PPTX 첨부 |
| 안전장치 | 동시에 두 번 실행되지 않게 잠금, 마지막 실행 결과(성공 · 실패 · 오류 내용) 기록, API 키는 코드가 아닌 스크립트 속성에 저장 |

### 미확인 · 주의
- **매일 08시 자동 실행**: 코드(`setupTrigger`)는 있지만 트리거 목록에는 대시보드용 수정 트리거 1개뿐 → **매일 자동 실행은 아직 켜져 있지 않음**. "매일 자동 발송 중"이라고 쓰지 않는다.
- 웹 앱 화면 캡처 없음

## B. 네이버 쇼핑 키워드 리포트

### 흐름
상품 목록 붙여넣기 → 가격 · 판매처 · 브랜드 분석 → 상품명 키워드 추출 → 네이버 데이터랩 12주 검색 추이 + 차트 → AI 콘텐츠 초안 → HTML 리포트 메일

### 실제로 돌아간 기록 (11-19, 검색어 "고양이빗")
| 단계 | 결과 |
|---|---|
| 0. 설정 · API 키 입력 | 완료 (3회) |
| 1. 상품 시트 정리 | 완료 · 51개 |
| 2. 상품 분석 | 완료 · 평균 22,494원, 가격대 · 판매처 · 브랜드 TOP 10 |
| 3. 키워드 추출 | **6번 실패** 후 마지막 실행도 실패 (실패 ③ · ⑤) → AI 분석 칸 비어 있음 |
| 4. 트렌드 조회 | 3번 실패(실패 ④) 후 **완료** · 12주 추이, 슬리커 +14.8% / 브러쉬 -54.1% |
| 5. 콘텐츠 만들기 | 3번 실패 · 1번 5분 넘게 걸려 중단 후 **완료**(15.6초) · 릴스 대본 · 카드뉴스 · 상세 카피 생성 |
| 6. 리포트 메일 | **실행 기록 없음** |
| 매주 자동 발송 | **트리거 없음** |

### 실제 코드(편집기)
- 파일 7개(step0~6). PC의 코드 파일보다 새 버전.
- AI 호출은 NVIDIA로 바뀜. 예전 이름(`callClaude`)으로 부르는 곳도 내부에서 NVIDIA 호출로 넘김.
- [NVIDIA API 연결 테스트] 메뉴, 설정 시트를 고치는 `repairSettings_`가 추가됨.

### 미확인 · 주의
- 리포트 메일 발송, 전체 실행(1→6), 매주 자동 발송 — 모두 실행 기록 없음
- AI가 만든 문구에 외국어 단어("calidad")가 섞여 나옴 → 사람이 검수해야 하는 근거

## C. AI 채널 콘텐츠 생성기

- 시트 메뉴 [AI 콘텐츠]: API 키 등록 · 시트 준비 · 선택한 행 생성 · 빈 행 모두 생성
- 입력: 경쟁상품 비교(쿠팡 폼롤러 3개) → 우리 상품 장점, 고객 페르소나 1명
- 출력(행마다): 인스타 카드뉴스 5장 · 릴스 30초 대본 · 블로그 제목 3개 + 도입부 · 상세페이지 첫 화면 카피 · 이미지 프롬프트(Firefly용) · 상태 `완료 + 시각`
- 실행 기록(11-18): API 키 등록 → 선택한 행 생성 3번, 모두 완료(19~24초)
- API 키는 **사용자 개인 속성**에 저장 → 시트를 공유해도 다른 사람에게 키가 보이지 않음
- 미확인: 경쟁 비교 · 페르소나를 직접 조사했는지, 생성 결과를 실제로 썼는지

## 실패와 해결 — 한계를 어떻게 보완했나

실행 기록의 오류 로그를 근거로 정리했다. 포트폴리오에는 "무엇이 안 됐고 → 왜 → 어떻게 고쳤나" 순서로 쓴다.

### ① AI가 생각만 하다가 답을 못 냄 (A · 11-20)
- **무엇이 안 됐나** 첫 테스트에서 AI 분석 결과가 비어 리포트를 만들지 못하고 멈췄다.
- **왜** 추론형 AI 모델이 허용된 글자 수(토큰 8,000개)를 거의 전부 "생각하는 과정"에 써 버려, 정작 답(JSON)을 쓸 자리가 남지 않았다. (로그: 추론 토큰 7,999개 · 답 없음 · 한도 도달)
- **어떻게 고쳤나**
  - 생각하는 양을 줄이도록 설정(`reasoning_effort: low`)
  - AI에게 보내는 자료를 줄임(영상마다 태그 3개만)
  - 답이 비었는지 · 잘렸는지를 먼저 확인하고, 문제면 원인을 기록하고 멈추게 함
- **결과** 12분 뒤 전체 실행 성공, 이후 실행 모두 성공.

### ② 웹 앱을 열면 계속 오류 (A · 11-22)
- **무엇이 안 됐나** 웹 앱 주소를 열 때마다 화면이 안 뜨고 10번 연속 실패했다.
- **왜** 배포해 둔 2번째 버전에 웹 앱 화면을 만드는 함수(`doGet`)가 없었다. 코드를 고쳐도 배포를 다시 하지 않으면 예전 버전이 계속 열린다. (로그: "doGet 함수를 찾을 수 없습니다")
- **어떻게 고쳤나** 웹 앱 함수를 추가하고 3번째 버전으로 다시 배포했다.
- **결과** 이후 웹 앱 열기 10번 모두 정상.

### ③ 쓰던 AI 모델이 하루 전에 서비스 종료 (B · 11-19)
- **무엇이 안 됐나** 키워드 분석과 콘텐츠 만들기에서 AI 호출이 실패했다.
- **왜** 쓰던 모델(`openai/gpt-oss-20b`)이 2026-11-18에 지원이 끝나 더 이상 호출할 수 없었다. (로그: 410 Gone · end of life)
- **어떻게 고쳤나** 현재 제공되는 모델(`nvidia/nemotron-3.5-lightning-30b-a3b`)로 바꾸고, 모델을 바꿔도 바로 확인할 수 있게 [NVIDIA API 연결 테스트] 메뉴를 추가했다.
- **결과** 콘텐츠 만들기 성공.

### ④ 검색 추이 API 인증 실패 (B · 11-19)
- **무엇이 안 됐나** 네이버 검색 추이 조회가 3번 실패했다.
- **왜** 데이터랩 검색어 트렌드는 NAVER API HUB에서 새로 받은 키만 쓸 수 있는데, 맞지 않는 키가 들어가 있었다. (로그: 401 Authentication Failed)
- **어떻게 고쳤나** 오류 메시지에 "API HUB에서 구독했는지, API HUB 키인지 확인"이라는 해결 방법을 같이 띄우게 하고, [처음 설정]에서 키를 다시 입력했다.
- **결과** 키를 다시 넣은 1분 뒤 조회 성공.

### ⑤ 설정 시트의 항목 이름이 달라 값을 못 찾음 (B · 11-19)
- **무엇이 안 됐나** 키워드 추출과 콘텐츠 만들기가 "검색어 값이 없습니다"로 7번 멈췄다.
- **왜** 코드는 설정 시트 A열에서 정확히 "검색어"라는 글자를 찾는데, 시트의 항목 이름이 달라져 있었다.
- **어떻게 고쳤나** "A열 항목을 '검색어'로 고치고 B열에 값을 넣으세요"처럼 무엇을 고치면 되는지 알려주는 메시지로 바꾸고, 설정 시트를 바로잡는 기능(`repairSettings_`)을 추가했다.
- **결과** 콘텐츠 만들기 성공. 키워드 추출은 고친 뒤 다시 실행한 기록이 없다.

### ⑥ AI 응답이 너무 느려 5분 넘게 멈춤 (B · 11-19)
- **무엇이 안 됐나** 콘텐츠 만들기가 5분(306초) 넘게 끝나지 않아 중단했다.
- **왜** AI가 만들 수 있는 글 길이 상한이 커서 응답이 오래 걸렸다(정확한 원인은 로그에 없음).
- **어떻게 고쳤나** 코드를 "빠른 응답 버전"으로 바꾸고 AI 글 길이 상한을 1,600토큰으로 낮췄다.
- **결과** 다음 실행은 15.6초 만에 완료.

### 처음부터 막아 둔 문제 (실패 기록은 없지만 코드에 대비가 있음)
- 웹 앱 버튼과 체크박스를 동시에 눌러도 두 번 돌지 않게 잠금
- 슬라이드 칸을 넘치지 않게 항목별 글자 수 자르기
- 네이버 쇼핑 검색 API 종료(2026-07-31)에 맞춰 상품 목록은 붙여넣기 방식으로 전환
- 데이터랩 주간 데이터의 마지막 주가 잘리지 않게 날짜별로 받아 7일씩 직접 묶음

## 포트폴리오에 쓸 수 있는 사실

- YouTube API → Sheets → NVIDIA AI → Slides → PDF · PPTX → 메일 첨부까지 **한 번 실행으로 이어지는 파이프라인**, 결과물 PDF · PPTX와 **메일 수신 확인**
- 같은 자동화를 편집기 · 시트 체크박스 · 웹 앱 세 가지 방법으로 실행
- 실행 기록: 전체 실행 5번 성공(11-20 1번, 11-22 4번), 수집 500행, AI 리포트 5건
- AI 답을 형식 · 항목 · 개수 · 잘림 여부로 검사한 뒤에만 문서로 만듦
- 실패 ①~⑥을 원인 확인 → 수정 → 재실행 성공으로 해결한 기록
- 네이버 데이터랩 API로 12주 검색 추이를 받아 상승 · 하락 판정 + 차트
- 시트 행 단위 AI 콘텐츠 생성(3개 상품 완료)

## 추가로 준비하면 좋은 증거

1. 유튜브 리포트 메일 캡처를 메일 주소를 가린 이미지 파일로 저장
2. 웹 앱 실행 센터 화면 캡처
3. 대시보드 시트 캡처(실행 상태 · 생성 파일 링크)
4. Apps Script 실행 기록 화면 캡처 — 실패 → 성공 흐름이 한 화면에 보여 문제 해결 근거로 좋음
5. (선택) 매일 자동 실행을 켜고 며칠 돌린 기록, 쇼핑 리포트 메일 1회 발송

> 개인정보: 메일 주소 · API 키 · 시트 주소는 포트폴리오와 캡처에 노출하지 않는다.
